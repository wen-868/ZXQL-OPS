## 4. 流程完善补丁（行业 SOP 映射）

行业"七大模块 SOP" → 本运营系统映射：

| 行业 SOP 模块 | 本运营系统对应 | 完善动作 |
|---|---|---|
| 账号定位与搭建 | B 账号矩阵 | 账号定位模板、人设档案标准化 |
| 短视频内容生产 | C/D/E/F/G/H | 工业化六步法固化 |
| 短视频流量运营 | I/S | 发布 + 投流联动流程 |
| 直播全流程运营 | K | 直播 SOP 固化（准备→开播→中控→结束→复盘）|
| 用户私域运维 | U | 私域 SOP（承接→分层→复购）|
| 数据复盘迭代 | J/M | 复盘 SOP（回收→诊断→再分析）|
| 合规风控管理 | P/K | 合规 SOP（实时监测+预检+处置）|

**短视频工业化六步法**（固化为标准流程）：
```
选题策划 → 脚本撰写 → 画面生成 → 剪辑合成 → 发布分发 → 数据复盘
   (C/D)      (E/F)      (G)         (H)        (I/S)       (J/M)
```

**直播全流程 SOP**：
```
准备(选品/脚本/素材/私域宣发/商品审核) → 开播 → 中控(商品/福袋/互动/AI代播) → 结束 → AI复盘
   (T/R/K/U)                        (K)        (K)                      (K)     (K/J)
```

**合规风控 SOP**（独立显式）：选题合规 → 脚本合规校验 → 发布前预检 → 直播违禁词实时监测 → 违规处置复盘。
