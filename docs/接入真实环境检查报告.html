📋 推荐接入顺序

  1. P0 核心路径
    ① 抖音发布真实接入：配置 OPS_DOUYIN_APP_ID/SECRET → 发布链路从模拟回执变为真实上传+发布（DouyinClientService 代码已就绪）
    影响：I 发布模块 → B 账号矩阵 → L 数据看板
  2. P0 核心路径
    ② 管理系统对接（订单/商品/佣金）：配置 OPS_MS_CLIENT_ID/SECRET + 设 OPS_INTEGRATION_MODE=connected → Y/R/T/W 四个模块全部切换到真实适配器
    影响：Y 订单 → R 商品 → T 选品 → W 佣金 → M 决策看板
  3. P1 重要
    ③ 对象存储接入：配置 OPS_OSS_* → 素材/视频文件存储从本地磁盘迁移到云存储（支持 CDN 分发）
    影响：G 素材中心 → H 智能成片 → I 发布上传
  4. P1 重要
    ④ 智能成片管道升级：从黑场占位 → 真实分镜拼装（场景切换/字幕/配音/多比例）
    影响：H 智能成片 → F 脚本联动 → G 素材联动 → I 发布
  5. P2 增强
    ⑤ 管理系统租户同步：配置服务账号后，Auth syncTenant/listAccounts 从 stub 变为真实回调
    影响：Auth 认证 → 多租户管理
  6. P2 可选
    ⑥ 飞书告警通知：配置 FEISHU_WEBHOOK_URL（非阻塞，当前本地日志完整）
    影响：N 审计告警
  7. P2 增强
    ⑦ Media Provider 集成（即梦/可灵）：对接真实 AI 视频/画面生成 API，替代当前 LLM 文本占位
    影响：G 素材中心 → H 智能成片
